This is an R Shiny app that helps with segmentation. 
It takes a data file with two columns. The first column should be called Response_ID and should have a participant number or something similar.
The second column should be called Text and holds the textual responses of the participants.

This app is based on Strijbos, J.-W., Martens, R. L., Prins, F. J., & Jochems, W. M. (2006). Content analysis: What are they talking about? Computers & Education, 46(1), 29–48. https://doi.org/10.1016/j.compedu/2005.04.002

The app can be run on https://01a11abe-9e3b-8778-dfdd-53c3629f13e4.share.connect.posit.cloud/ or locally.
