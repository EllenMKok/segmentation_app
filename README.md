This is an R Shiny app that helps with segmentation. 
It takes a data file with two columns. The first column should be called Response_ID and should have a participant number or something similar.
The second column should be called Text and holds the textual responses of the participants.


The app can be run on https://connect.posit.cloud/ellenmkok/content/01a11abe-9e3b-8778-dfdd-53c3629f13e4 or locally.
